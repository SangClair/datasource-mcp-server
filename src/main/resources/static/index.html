将上述地址配置到支持 Streamable HTTP 的 MCP 客户端（如 Cursor、Qoder）即可调用数据工具。
若服务端配置了访问令牌，MCP 客户端也需在连接中携带请求头 X-Access-Token。

令牌通过请求头 X-Access-Token 发送，并保存在当前浏览器本地。修改后点击「应用并刷新」重新加载列表；未配置服务端令牌时可留空。
